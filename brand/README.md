# Լոգոն

`logo-source.png`-ը **բնօրինակն** է՝ կանաչ շրջան, նրա մեջ սպիտակ նշիչ, նշիչի
ներսում՝ ծիրան։ Ամեն ինչ մնացածը գեներացվում է դրանից՝

```
npm run brand
```

Փոխարկիչը ինքը գտնում է շրջանը և նշիչը նկարի մեջ, ապա գունավոր ֆոնը վերագծում է
մաքուր գույնով և վերցնում միայն նշիչը։ Այդ պատճառով ֆայլերը և՛ ավելի մաքուր են,
և՛ մի քանի անգամ ավելի փոքր, քան պարզապես չափափոխելու դեպքում։

## Ինչ է ստացվում

| Ֆայլ | Որտեղ | Ինչու այդպես |
| --- | --- | --- |
| `public/logo.webp` | Էջի վերնագիրը և մուտքի էկրանը | Թափանցիկ շրջանից դուրս |
| `public/favicon-96.png` | Բրաուզերի ներդիրը | |
| `public/icon-192.png` | iPhone-ի հիմնական էկրան | Սպիտակ ֆոնով. թափանցիկ apple-touch-icon-ը սև է դառնում |
| `public/icon-512.png` | Հավելվածի ցանկեր | |
| `public/icon-maskable-512.png` | Android-ի հիմնական էկրան | Կանաչը հասնում է չորս անկյուն. հեռախոսն ինքն է որոշում՝ շրջան, քառակուսի թե այլ ձև |
| `public/og-image.png` | Messenger-ում, Facebook-ում, LinkedIn-ում հղումը փակցնելիս | 1200×630 |

Նոր լոգո դնելու համար փոխարինե՛ք `logo-source.png`-ը և գործարկեք `npm run brand`։
