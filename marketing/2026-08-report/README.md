## Հաջորդ ամիսը

`cards.html`-ը բացվում է բրաուզերով և խմբագրվում է որպես սովորական HTML։
Թվերը գրված են անմիջապես markup-ի մեջ, շերտերի երկարությունը՝ `width`
տոկոսով։ Նոր քարտեր ստանալու համար բավական է փոխել թվերն ու տոկոսները,
ապա ամեն `.card`-ի սքրինշոթը վերցնել 1080×1080 չափով։
