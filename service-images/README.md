# Ապրանքների և ծառայությունների նկարներ

Այս պանակի նկարները ցուցադրվում են «Գյուղատնտեսական ծառայություններ» բաժնում՝
էմոջիների փոխարեն (քարտեզի կետերի, առաջարկների քառակուսիների և որոնման
կոճակների վրա)։

## Ինչպես պահել

- Ֆայլի անունը պետք է լինի ստորև աղյուսակի **անգլերեն անունը** ճշգրիտ, օրինակ՝
  `pesticide.png`, `seeds.png`։
- Թույլատրված ձևաչափեր՝ PNG, JPG, WebP։ Ամենալավը՝ PNG թափանցիկ ֆոնով։
- Նկարը կարող է լինել ցանկացած չափի. GitHub-ն ինքը կփոքրացնի։
- `_` և `-` նշանները հավասար են (`spare_parts.png` = `spare-parts.png`)։
- Սխալ անունով նկարը կայքում չի երևա, և GitHub-ը նամակով կտեղեկացնի։

| Ֆայլի անունը | Ինչ է |
|---|---|
| `seeds` | Սերմեր |
| `seedlings` | Տնկիներ |
| `fertilizer` | Պարարտանյութ |
| `pesticide` | Թունաքիմիկատներ |
| `irrigation-systems` | Ոռոգման համակարգեր |
| `hail-nets` | Հակակարկտային ցանց |
| `greenhouses` | Ջերմոցներ |
| `machinery` | Գյուղտեխնիկա |
| `heavy-machinery` | Ծանր գյուղտեխնիկա |
| `spare-parts` | Պահեստամասեր |
| `tools` | Գործիքներ |
| `fodder` | Անասնակեր |

## Կրեդիտներ խնայելու համար

Բոլոր նկարները վերբեռնիր **մեկ անգամից** («Add files → Upload files», մի քանի
ֆայլ միասին)։ Նկարների վերբեռնումն ինքնին կայքը չի թարմացնում. նկարները կայքում
կհայտնվեն կայքի հաջորդ թարմացման հետ կամ երբ Netlify-ում սեղմես
**Deploys → Trigger deploy → Deploy project**։
