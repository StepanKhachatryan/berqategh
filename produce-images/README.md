# Բերքի նկարներ

Այստեղ դրե՛ք **բնօրինակ** նկարները։ Մշակված, սեղմված տարբերակները գնում են
`src/assets/produce/`-ում — դրանք ձեռքով չեն դրվում, գեներացվում են։

## Ինչպես ավելացնել նկար

1. Ֆայլը դրե՛ք այս թղթապանակում (`.png`, `.jpg` կամ `.webp`)
2. Անվանե՛ք ապրանքի **id**-ով՝ `apple.png`, `peach.png`, `tomato.png`
3. Գործարկե՛ք `npm run icons`
4. Վերջ — հավելվածն ինքը կվերցնի այն

Եթե նկար չկա, ապրանքը ցույց է տալիս էմոջին, ինչպես հիմա։ Երկուսը կարող են
կողք կողքի գոյություն ունենալ, ուստի նկարներն ավելացրե՛ք այնքան, որքան պատրաստ են։

## Պահանջներ

| Ինչ | Ինչու |
| --- | --- |
| **PNG՝ թափանցիկ ֆոնով** կամ **JPG՝ մաքուր սպիտակ ֆոնով** | Իկոնը նստում է սպիտակով լցված շրջանակի մեջ։ Թափանցիկ PNG-ն ամենաապահովն է. սպիտակ ֆոնով JPG-ն նույնպես աշխատում է, քանի որ ֆոնը միաձուլվում է շրջանակին։ Մոխրագույն, գունավոր կամ շախմատաձև ֆոնը կերևա որպես ուղղանկյուն |
| Առնվազն 256×256, նախընտրելի է **1024-ից ոչ ավելի** | Փոքրացնելը լավ է ստացվում, մեծացնելը՝ ոչ։ Բայց 4000px-անոց բնօրինակը ~9 ՄԲ է և ընդմիշտ մնում է git-ի պատմության մեջ, մինչդեռ արդյունքը միևնույն է 128px է |
| Մեկ առարկա, կենտրոնում | Ֆոնի ավելորդ տարածքն ինքնաշխատ կտրվում է, ուստի եզրերի տեղը կարևոր չէ |
| Մեկ առարկա, առանց ստվերի | 23px-ի վրա ստվերը վերածվում է կեղտի |

## Ապրանքի id-ները

Ամբողջ ցանկը՝ `src/data/produce.ts`-ում։ Օրինակներ՝

`apple` խնձոր · `pear` տանձ · `peach` դեղձ · `apricot` ծիրան · `plum` սալոր ·
`grape` խաղող կարմիր · `grape-white` խաղող սպիտակ · `tomato` լոլիկ ·
`cucumber` վարունգ · `potato` կարտոֆիլ · `garlic` սխտոր · `walnut` ընկույզ

## Ինչ է անում `npm run icons`

Ամեն բնօրինակ դառնում է **128×128 WebP**՝ թափանցիկությունը պահպանելով, մոտ
4–8 KB։ Հավելվածում ամենամեծ չափը 62px է, ուստի 128-ը retina-ի համար բավական է,
իսկ ավելի մեծը ուղղակի ծավալ է ուտում առանց տեսանելի օգուտի։

## Եթե `npm run icons`-ը չի աշխատում

Փոխարկիչը Chromium-ի վրա է. այն հավելվածի կախվածություն չէ, որովհետև կայքի
build-ին պետք չէ։ Մեկ անգամ՝

```
npm i -g playwright && npx playwright install chromium
```

**The name must be the crop id exactly** - `grape.png`, not `grape_red.png`.
A picture whose name matches no crop is converted but never shown. The
workflow checks this and fails (with a "did you mean" hint) when a name is off;
run `npm run icons:check` to check locally.
